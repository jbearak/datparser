datparser @VERSION@

An R package repository for datparser, whose read_fixed_width() reads fixed-width text through its SAS setup file. It holds binaries for macOS (arm64), Windows (x86_64) and Ubuntu 24.04 (x86_64) for the current and previous R releases, and the source package, which needs Rust to build.

macOS and Windows

install.packages("datparser", repos = c("https://jbearak.github.io/datparser", "https://cloud.r-project.org"))

Ubuntu 24.04

install.packages("datparser", repos = c(
  sprintf("https://jbearak.github.io/datparser/bin/linux/noble-x86_64/%s", getRversion()[, 1:2]),
  "https://cloud.r-project.org"
))
